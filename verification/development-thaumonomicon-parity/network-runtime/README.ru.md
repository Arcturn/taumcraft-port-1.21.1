# Два клиента: LAN integrated server

PASS. Это два реальных клиента в опубликованном одиночном мире (LAN),
не два клиента на выделенном сервере. Проверки GameTest на сервере имеют
отдельные журналы и не меняют область этого сетевого результата.

Подтверждены разные UUID, чистый второй игрок, независимость прогресса,
однократные 10 XP при FIRSTSTEPS, раздельные RESEARCH/PAGE, различие открытия
через поиск и через узел дерева, повторный вход после перезапуска клиента
и сохранение после полного перезапуска мира хозяина. Сообщение о приложении
показано один раз и не повторялось при повторном входе.

Дополнительный реальный прогон: kill, нажатие Respawn, поездка в Nether и
обратно, затем открытие книги для нового серверного снимка. Стадии, отметки,
известные аспекты, постоянное искажение, UUID и XP сохранены. На время
проверки смерти использовалось keepInventory=true.

Точные сравнения и ограничения — summary.json, respawn-comparison.json,
death-dimension-comparison.json. Исходные properties, журналы и снимки
сохранены рядом. Часть ранних попыток переподключения не удалась; итоговые
проверки относятся к успешному новому запуску и подтверждённому входу.
