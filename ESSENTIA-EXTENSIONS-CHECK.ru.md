# Проверка alpha.7: буфер, мехи, расширения, тауматориум

Установить JAR alpha.7 вместо прежнего JAR порта. Minecraft 1.21.1 / NeoForge / Java 21 / Curios. Ниже команды для отдельного тестового мира с разрешёнными командами. Координаты абсолютные: сначала выберите свободную область возле 0,100,0. Не запускайте команды поверх построек.

## Тауматориум: полный короткий цикл

```mcfunction
/gamemode creative
/thaumcraft research grant THAUMATORIUM
/thaumcraft research grant METALLURGY
/give @s thaumcraft:salis_mundus
/give @s minecraft:iron_ingot 8
/setblock 0 99 0 minecraft:magma_block
/setblock 0 100 0 thaumcraft:crucible
/setblock 0 101 0 thaumcraft:metal_alchemical
/setblock 0 102 0 thaumcraft:metal_alchemical
/tp @s 0.5 101 4.5 180 25
```

- [ ] Стоя с южной стороны и глядя на конструкцию, нажать Salis Mundus на нижней алхимической конструкции. Появляются две половины тауматориума, звук и частицы. Тигель остаётся снизу; вода для тауматориума не требуется.
- [ ] ПКМ пустой рукой по любой половине открывает один общий инвентарь. Положить железо в левый слот; справа появляется таумиевый слиток. Нажать его: зелёная отметка означает выбранный рецепт. Это кнопка выбора, взять результат из неё нельзя.

Подать две эссенции с боков:

```mcfunction
/setblock 1 101 0 thaumcraft:tube
/setblock 2 101 0 thaumcraft:alembic{Aspect:"praecantatio",Amount:64}
/setblock -1 101 0 thaumcraft:tube
/setblock -2 101 0 thaumcraft:alembic{Aspect:"terra",Amount:64}
```

- [ ] На 1 железный слиток расходуется по 5 Praecantatio и Terra. Таумиевый слиток выпадает перед машиной; рецепт остаётся выбранным для следующего изготовления.
- [ ] Передняя грань не подключает трубу. Нижняя половина принимает эссенцию с боков, верхняя — с боков и сверху; выходов эссенции нет.
- [ ] Во время накопления убрать магму: работа останавливается, накопленные аспекты сохраняются. Вернуть магму — работа продолжается.
- [ ] Поставить источник редстоуна сбоку от свободной грани: машина останавливается. Убрать — продолжает. Учесть интервал проверки до 5 тиков.
- [ ] Выйти из мира посреди накопления, войти: железо, рецепт, автор выбора и аспекты сохранены. Команда для наблюдения: `/data get block 0 101 0`.
- [ ] Убрать тигель: обе половины превращаются обратно в алхимические конструкции, катализатор выпадает; накопленная эссенция переходит во flux. Сделать это только после проверки сохранений.

## Буфер и мехи

```mcfunction
/setblock 6 101 0 thaumcraft:tube_buffer{Contents:{aer:4,ignis:6}}
/setblock 6 100 0 thaumcraft:jar_normal{Filter:"ignis"}
/setblock 7 101 0 thaumcraft:bellows[facing=west,enabled=true]
/give @s thaumcraft:thaumometer
```

- [ ] Без мехов тяга буфера 1; с одним активным мехом 32, с двумя 64. Мех должен смотреть в буфер. После изменения ждать до 20 тиков.
- [ ] В примере банка под буфером сначала не перетягивает его при равной тяге 64, если установлены два меха. С одним мехом помеченная банка должна забрать только Ignis, оставив Aer.
- [ ] ПКМ таумометром по стороне буфера отключает/включает соединение; Shift+ПКМ переключает режим: обычная тяга → тяга 1 (жёлтая отметка) → тяга 0 (красная отметка). Нулевая тяга не запрещает отдавать эссенцию; для полного отсечения отключите соединение.
- [ ] При двух совместимых потребителях с разной тягой эссенцию получает более сильный. Несовместимый аспект не блокирует другого потребителя.
- [ ] Общая вместимость 10, даже если аспектов несколько. `/data get block 6 101 0 Contents` показывает остатки. После перезахода проверить также `Chokes` и `Open`.
- [ ] Мехи сжимаются/разжимаются; слышен тихий исходный звук. Редстоун отключает мех и его влияние на тягу. В этой версии мехи ещё не ускоряют обычную ванильную печь.

## Расширения алхимической печи

```mcfunction
/setblock 12 101 0 thaumcraft:smelter_basic[facing=north]
/setblock 12 102 0 thaumcraft:alembic
/setblock 13 101 0 thaumcraft:smelter_aux[facing=west]
/setblock 13 102 0 thaumcraft:alembic
/setblock 11 101 0 thaumcraft:smelter_vent[facing=east]
/setblock 12 101 1 thaumcraft:bellows[facing=north,enabled=true]
/give @s minecraft:coal 32
/give @s minecraft:stone 64
```

- [ ] Положить камень и топливо в печь. Основная колонна кубов и колонна над дополнительным насосом получают эссенцию. Каждый насос добавляет один перенос за исходный период дистилляции.
- [ ] Один/два/три меха с непередних горизонтальных сторон уменьшают время переплавки до 87,5% / 75% / 62,5%, с округлением вниз и минимумом 1 тик.
- [ ] Вентиляция уменьшает потери во flux: на каждую потерянную единицу каждый вентиль получает независимый шанс 0,333 её убрать. Это вероятность, не фиксированное уменьшение на треть в каждой плавке. Во время срабатывания появляется пар.
- [ ] Насос/вентиляция должны смотреть в печь и не ставятся на её переднюю грань. Если убрать печь, прикреплённый блок выпадает.
- [ ] На трёх типах печи проверить отсутствие чёрно-фиолетовых текстур; перезаход сохраняет топливо, таймеры и эссенцию.

## Мнемонические матрицы, меню и сеть

```mcfunction
/give @s thaumcraft:brain_box 4
/give @s thaumcraft:mind_clockwork
```

- [ ] Поставить матрицу на бок тауматориума, направив к нему: лимит выбранных рецептов увеличивается на 2. После снятия лишние рецепты в конце списка удаляются, предметы не создаются.
- [ ] Перелистывание `<` / `>` и снятие всех выборов `×` не забирают предметы из каталога. Shift-клик, перетаскивание и Creative-клонирование превью не выдают бесплатных результатов.
- [ ] Воронка/автоматизация видит общий слот катализатора через обе половины. Проверить повторно после разборки и сборки.
- [ ] Два игрока открывают меню одновременно: выбор, остатки и результат согласованы, нет двойного расхода/выдачи. Игрок без исследования не выбирает закрытый рецепт. Автоматическая работа использует сохранённое исследование автора выбора, даже когда он офлайн.

Это **чек-лист для выполнения**, не журнал пройденных игровых испытаний. Автоматически проверены алгоритмы, зарегистрированные объекты, сериализация, рецепты и ресурсы. Клиент/OpenGL, тики настоящего мира, сетевые гонки и выгрузка чанков здесь не запускались.
