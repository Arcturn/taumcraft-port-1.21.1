# Thaumcraft: Renaissance — Minecraft 1.21.1

Экспериментальный неофициальный перенос Thaumcraft 6 на NeoForge. Текущая версия: **0.1.0-alpha.9.26-dev**. Перенос игровых систем ещё продолжается. Идентификатор мода остаётся `thaumcraft`, чтобы сохранить совместимость предметов и блоков с существующими мирами.

В alpha.9.26 перенесён раздел «Наполнение» TC6 BETA26: руническая матрица, три вида алтаря и пьедесталов, стабилизатор и красная инкрустация, камни скорости/затрат, ритуалы, нестабильность и её последствия. Добавлены элементальные инструменты, сапоги путешественника, крепостная броня с масками и очками, руническая защита, восемь зачарований наполнения, аксессуары, знамёна и зачарованные дорожные блоки. Зарядные предметы используют вис из ауры через зарядный пьедестал. Из связанных основ добавлены мантии и перчатка для управления матрицей и трубами; система фокусов и заклинаний ещё не перенесена.

Все 47 ссылок на рецепты в 17 записях раздела связаны с реальными рецептами или схемами алтаря; 28 рецептов выполняются самой матрицей. Алтарь собирается Salis Mundus из восьми камней, пьедестала и матрицы, затем активируется перчаткой. Ритуал сохраняет оплаченные ресурсы и незавершённое состояние; изменение компонентов центрального предмета прерывает его, чтобы не потерять новые данные предмета. Проверки охватывают расход эссенции/компонентов, сохранение, нестабильность, эффекты экипировки и защиту от дублирования ресурсов. Модели и поведение сверяются с исходниками и запущенным оригинальным TC6.

Алхимия из alpha.9.25 сохранена: тигель и тауматориум, переработка и транспорт эссенции, жидкости, ванна, урна, распылитель, конденсатор, свечи и таумиевое снаряжение. Очистка олова, серебра и свинца использует общие теги других модов; элементальная кирка и зачарование очистки теперь могут давать соответствующие кластеры.

Полная цепочка выживания пока ограничена контентом других разделов. Зарядный пьедестал и связанные исследования требуют ещё не перенесённых фокуса и фокального манипулятора из тауматургии; мясные крупицы для поддерживающего амулета добываются в ещё не перенесённой Адской печи; генерация древнего/древнего потустороннего камня также остаётся за пределами этого переноса. Оригинальные условия не обходятся. Система тяжести событий искажения пока отсутствует, поэтому эффект смягчения событий у маски «Ухмыляющийся дьявол» подготовлен в коде, но ещё не проявляется в игре. Остальные две маски действуют в бою.

Каталог сохраняет все 148 записей и 271 этап оригинала. Осталось 5 неподдерживаемых предметных требований в 4 записях: три уровня фокусов, фокальный манипулятор и зеркальное стекло. Это аудит регистрации предметов, а не утверждение, что весь Thaumcraft уже проходим в выживании.

В `thaumcraft-common.toml` настройка `research.noSleep` позволяет получить дневник сразу при первом подборе кристалла; по умолчанию, как в TC6, сначала нужно поспать.

## Сборка

Нужны **JDK 21**, Git и интернет для загрузки зависимостей.

```sh
git clone https://github.com/Arcturn/taumcraft-port-1.21.1.git
cd taumcraft-port-1.21.1
```

Windows PowerShell:

```powershell
.\gradlew.bat build
```

Linux / macOS:

```sh
./gradlew build
```

`build` компилирует мод и запускает JUnit-тесты. Готовый мод: `build/libs/thaumcraft-renaissance-1.21.1-alpha.9.26.jar`. Для установки нужен основной JAR без суффикса `-sources`. При обновлении удалите предыдущий JAR этого мода из папки `mods`, чтобы не загрузить две копии.

Для игры установите **NeoForge 21.1.259** и **Curios 9.5.1+1.21.1**. TerraBlender 1.21.1-4.1.0.8 включается в JAR автоматически. Клиент и сервер должны использовать одинаковую версию порта.

Для запуска клиента из исходников: `./gradlew runClient` (Windows: `.\gradlew.bat runClient`). Дополнительные проверки: `./gradlew runData runGameTestServer`.

В репозитории находятся код, игровые ресурсы, тесты и файлы сборки. Отчёты сравнений, эталонный архив TC6, снимки экрана и видео сюда не включаются. Исходники ведутся в GitHub.
