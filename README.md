# Thaumcraft: Renaissance — Minecraft 1.21.1

Экспериментальный неофициальный перенос Thaumcraft 6 на NeoForge. Текущая версия: **0.1.0-alpha.9.23-dev**. Перенос игровых систем ещё продолжается. Идентификатор мода остаётся `thaumcraft`, чтобы сохранить совместимость предметов и блоков с существующими мирами.

В alpha.9.23 восстановлены интерфейс и правила работы тауматориума по TC6 BETA26: выбор рецептов, индикаторы эссенции, улучшения мозговыми блоками и выдача результата в инвентарь перед выходом. Очки откровения получили оригинальный крафт, свойства брони, ношение через Curios, отображение эссенции и нот, свечение разломов и скидку 5% на vis при ношении.

## Сборка

Нужны **JDK 21**, Git и интернет для загрузки зависимостей.

```sh
git clone https://github.com/Arcturn/taumcraft-port-1.21.1.git
cd taumcraft-port-1.21.1
```

Windows PowerShell:

```powershell
.\gradlew.bat build
```

Linux / macOS:

```sh
./gradlew build
```

`build` компилирует мод и запускает JUnit-тесты. Готовый мод: `build/libs/thaumcraft-renaissance-1.21.1-alpha.9.23.jar`. Для установки нужен основной JAR без суффикса `-sources`. При обновлении удалите предыдущий JAR этого мода из папки `mods`, чтобы не загрузить две копии.

Для игры установите **NeoForge 21.1.259** и **Curios 9.5.1+1.21.1**. TerraBlender 1.21.1-4.1.0.8 включается в JAR автоматически. Клиент и сервер должны использовать одинаковую версию порта.

Для запуска клиента из исходников: `./gradlew runClient` (Windows: `.\gradlew.bat runClient`). Дополнительные проверки: `./gradlew runData runGameTestServer`.

В репозитории находятся код, игровые ресурсы, тесты и файлы сборки. Отчёты сравнений, эталонный архив TC6, снимки экрана и видео сюда не включаются. Исходники ведутся в GitHub.
