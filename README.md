# Thaumcraft: Renaissance — Minecraft 1.21.1

Экспериментальный неофициальный перенос Thaumcraft 6 на NeoForge. Текущая версия: **0.1.0-alpha.9.25-dev**. Перенос игровых систем ещё продолжается. Идентификатор мода остаётся `thaumcraft`, чтобы сохранить совместимость предметов и блоков с существующими мирами.

В alpha.9.25 перенесены недостающие предметы, рецепты и механизмы раздела алхимии TC6 BETA26: жидкая смерть, очищающая жидкость, соли и мыло, бутылка заражения, мистическая ванна, неиссякающая урна, распылитель зелий, передатчики эссенции и резонатор. Добавлены сальные свечи, редкоземельные элементы, таумиевое снаряжение, недостающие превращения и получение кристаллов в тигле. Из связанных основ добавлены конденсатор флюкса и его решётки. Исправлены работа плавильни, клапанов, банок и взаимодействие урны с современными котлами.

Для всех 61 ссылок на рецепты в 22 записях алхимии проверяются настоящие серверные рецепты и игровые механики; декоративные изображения из книги не считаются реализованным предметом. Очистка олова, серебра и свинца использует ресурсы других модов через общие теги. Кварцевый кластер сохранён, но его добыча относится к ещё не перенесённым инструментам и зачарованиям инфузии.

Каталог сохраняет все 148 записей и 271 этап оригинала. Для 9 предметных требований в 8 записях ещё не перенесён нужный контент: перчатка заклинателя, фокусы, фокальный манипулятор, зеркальное стекло, матрица инфузии и два древних строительных блока. Поэтому передатчики эссенции, пустотная плавильня и конденсатор пока зависят от незавершённых исследований других разделов и не доступны по полной цепочке выживания. Оригинальные условия не обходятся. Для солей восстановлены счётчик и периодическая проверка искажения, открывающая скрытое исследование; прочие события искажения из раздела «Древние знания» ещё не перенесены.

В `thaumcraft-common.toml` настройка `research.noSleep` позволяет получить дневник сразу при первом подборе кристалла; по умолчанию, как в TC6, сначала нужно поспать.

## Сборка

Нужны **JDK 21**, Git и интернет для загрузки зависимостей.

```sh
git clone https://github.com/Arcturn/taumcraft-port-1.21.1.git
cd taumcraft-port-1.21.1
```

Windows PowerShell:

```powershell
.\gradlew.bat build
```

Linux / macOS:

```sh
./gradlew build
```

`build` компилирует мод и запускает JUnit-тесты. Готовый мод: `build/libs/thaumcraft-renaissance-1.21.1-alpha.9.25.jar`. Для установки нужен основной JAR без суффикса `-sources`. При обновлении удалите предыдущий JAR этого мода из папки `mods`, чтобы не загрузить две копии.

Для игры установите **NeoForge 21.1.259** и **Curios 9.5.1+1.21.1**. TerraBlender 1.21.1-4.1.0.8 включается в JAR автоматически. Клиент и сервер должны использовать одинаковую версию порта.

Для запуска клиента из исходников: `./gradlew runClient` (Windows: `.\gradlew.bat runClient`). Дополнительные проверки: `./gradlew runData runGameTestServer`.

В репозитории находятся код, игровые ресурсы, тесты и файлы сборки. Отчёты сравнений, эталонный архив TC6, снимки экрана и видео сюда не включаются. Исходники ведутся в GitHub.
