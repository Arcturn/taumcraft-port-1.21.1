# Thaumcraft: Renaissance — Minecraft 1.21.1

Экспериментальный неофициальный перенос Thaumcraft 6 на NeoForge. Текущая версия: **0.1.0-alpha.9.24-dev**. Перенос игровых систем ещё продолжается. Идентификатор мода остаётся `thaumcraft`, чтобы сохранить совместимость предметов и блоков с существующими мирами.

В alpha.9.24 исследования сверены с TC6 BETA26: восстановлены начало через кристаллы и сон, дневник сновидений, условия открытий при получении урона, сообщения об исследовании мира и опыт за открытия сканером. Исправлены расходование предметов, совместная работа за исследовательским столом, доступность небесных карт, анимация выбора карты и отображение накопленных процентов. Устаревшие ссылки в Таумономиконе теперь открывают существующие рецепты окраски нитора и меток эссенции.

Каталог сохраняет все 148 записей и 271 этап оригинала. Для 15 предметных требований в 10 записях ещё не перенесён нужный контент: в том числе перчатка заклинателя, фокусы, фокальный манипулятор и матрица инфузии. Поэтому наличие записи в книге пока не означает возможность пройти её и зависимые исследования в выживании.

В `thaumcraft-common.toml` настройка `research.noSleep` позволяет получить дневник сразу при первом подборе кристалла; по умолчанию, как в TC6, сначала нужно поспать.

## Сборка

Нужны **JDK 21**, Git и интернет для загрузки зависимостей.

```sh
git clone https://github.com/Arcturn/taumcraft-port-1.21.1.git
cd taumcraft-port-1.21.1
```

Windows PowerShell:

```powershell
.\gradlew.bat build
```

Linux / macOS:

```sh
./gradlew build
```

`build` компилирует мод и запускает JUnit-тесты. Готовый мод: `build/libs/thaumcraft-renaissance-1.21.1-alpha.9.24.jar`. Для установки нужен основной JAR без суффикса `-sources`. При обновлении удалите предыдущий JAR этого мода из папки `mods`, чтобы не загрузить две копии.

Для игры установите **NeoForge 21.1.259** и **Curios 9.5.1+1.21.1**. TerraBlender 1.21.1-4.1.0.8 включается в JAR автоматически. Клиент и сервер должны использовать одинаковую версию порта.

Для запуска клиента из исходников: `./gradlew runClient` (Windows: `.\gradlew.bat runClient`). Дополнительные проверки: `./gradlew runData runGameTestServer`.

В репозитории находятся код, игровые ресурсы, тесты и файлы сборки. Отчёты сравнений, эталонный архив TC6, снимки экрана и видео сюда не включаются. Исходники ведутся в GitHub.
