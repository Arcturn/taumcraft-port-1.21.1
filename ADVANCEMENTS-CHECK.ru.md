# Alpha.9.4 — закладки рецептов и достижения

Установить один JAR alpha.9.4 на клиент и сервер, затем перезапустить игру. В TC6 6.1.BETA26 собственного дерева достижений Minecraft не было: здесь добавлена новая интеграция с меню L по всем 148 оригинальным записям исследований. Ещё семь узлов обозначают категории и один — открытие книги, всего 156. Это не завершает отсутствующие игровые механики.

## Закладки рецептов

В отдельном тестовом мире с читами:

```mcfunction
/give @s thaumcraft:thaumonomicon
/thaumcraft research grant all
```

- [ ] Открыть книгу, затем исследование с несколькими рецептами, например «Металлургия» / METALLURGY. Справа видна полная фиолетовая полоска закладки с вырезом, отдельным краем и предметом. Синего фрагмента индикатора знаний вместо закладки больше нет.
- [ ] Навести на каждую закладку: полоска выдвигается; предмет смещается вместе с ней. Расположение слегка различается между закладками, но не дрожит по кадрам.
- [ ] Выбранная закладка краснеет. Повторный щелчок закрывает рецепт; щелчок по другой закладке открывает её рецепт. У правого края работает вся исходная область шириной 30 пикселей.
- [ ] У рецепта с вариантами значок на закладке циклически меняется, без наложенного количества предметов. Стрелки внутри рецепта продолжают переключать варианты.
- [ ] Левые закладки аспектов и знаний выдвигаются при наведении. На собственной странице типов знаний отдельная вкладка знаний отсутствует, как в TC6.
- [ ] Проверить масштаб интерфейса 2/3/4, F3+T и повторное открытие книги. Сравнить с TC6 без шейдеров и сторонних ресурс-паков.

## Получение достижений

Для проверки обычного прогресса использовать нового игрока/новый тестовый мир, где не применялся `research grant all`.

1. Получить книгу командой `/give @s thaumcraft:thaumonomicon` и открыть ПКМ. Через секунду открыть меню достижений клавишей L: появляется вкладка Thaumcraft.
2. Начать исследование «Первые шаги». Незаконченный этап не должен выдавать достижение завершения.
3. Выполнить все этапы. Должно появиться соответствующее достижение с исходным названием исследования. Достижения не тратят знания, предметы или искажение дополнительно.
4. Перезайти в мир: полученное достижение остаётся выполненным, повторного уведомления нет.
5. Проверить старое сохранение alpha.9.3 с завершёнными исследованиями: они засчитываются в течение секунды после входа. При необходимости открыть книгу, чтобы открыть корень дерева.
6. Сканирование виспа и других уже перенесённых существ должно выдавать связанные скрытые достижения по фактическому открытию соответствующей записи.
7. На сервере два игрока должны иметь разный прогресс. Достижения другого игрока не выдаются автоматически.

## Команды проверки

Завершить одно исследование и проверить настоящую серверную выдачу достижения:

```mcfunction
/thaumcraft research grant FIRSTSTEPS
```

Через секунду соответствующее достижение должно быть получено. Проверить всю существующую связку исследований и достижений:

```mcfunction
/thaumcraft research grant all
```

Открыть книгу и подождать секунду. Все 148 достижений исследований и семь разделов засчитываются; корень выдаётся за открытие книги. Команда может поставить в очередь много уведомлений о достижениях.

Для показа одного дерева Minecraft без изменения исследований:

```mcfunction
/advancement grant @s from thaumcraft:root
```

Эта ванильная команда выдаёт только достижения. Она не завершает исследования и не открывает отсутствующие механики. Если отозвать достижение уже завершённого исследования через `/advancement revoke`, сервер снова зачтёт его по сохранённому исследованию.

Скрытые записи отображаются по правилам Minecraft. Неперенесённые механики нельзя пройти в выживании только благодаря наличию узла; список оставшегося объёма — `PORTING-16.md`.

Автоматически проверены условия, все 156 JSON настоящим кодеком Minecraft, дерево и сохранение прогресса. Игровой клиент/OpenGL, реальные всплывающие уведомления, сетевое получение и визуальное совпадение закладок пока не запускались.
