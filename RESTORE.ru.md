# Получение и сборка alpha.9.17-dev

Minecraft 1.21.1; Java JDK 21; Gradle Wrapper 9.2.1; NeoForge 21.1.259; Curios 9.5.1+1.21.1; TerraBlender 1.21.1-4.1.0.8. Версии зафиксированы в `gradle.properties`. Сетевой протокол порта — 7; клиент и сервер должны использовать одну версию. Данные исследований используют schema 3 с миграцией прежних отметок чтения.

## Получение исходников

Установить Git и JDK 21, указать `JAVA_HOME`. Выполнить:

```sh
git clone https://github.com/Arcturn/taumcraft-port-1.21.1.git
cd taumcraft-port-1.21.1
```

Исходники и последующие изменения ведутся в этом репозитории. Порядок передачи готовых сборок описан в [DELIVERY.md](DELIVERY.md).

Репозиторий содержит `src` (код, ресурсы и тесты), Gradle Wrapper и конфигурацию, `tools`, `reference` (в том числе сохранённые исходники эталона), документацию и журналы проверок. Каталоги сборки, игровые миры, кеши Gradle, JDK и установленные клиенты Minecraft в исходники не входят. `gradle-wrapper.jar` и `libs/TerraBlender-neoforge-1.21.1-4.1.0.8.jar` — вспомогательные зависимости. Атрибуция и лицензии сторонних компонентов сохранены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Сборка

Для первой сборки нужен интернет к репозиториям Gradle, NeoForge, Mojang, Curios и Forge.

Windows PowerShell, из каталога проекта:

```powershell
.\gradlew.bat test runData runGameTestServer build
```

Linux или macOS:

```sh
./gradlew test runData runGameTestServer build
```

Если файловая система не сохранила право исполнения, выполнить `chmod +x gradlew` либо вызвать `bash gradlew test runData runGameTestServer build`.

Результат сборки: `build/libs/thaumcraft-port-1.21.1-0.1.0-alpha.9.17-dev.jar`. Для игры нужен также Curios 9.5.1+1.21.1; TerraBlender включён в JAR порта как вложенная зависимость.

Материалы в `reference` не входят в source set и не компилируются с портом. Повторный импорт исходных ресурсов для обычной сборки не нужен. Исторические `tools/import_*` могут требовать отдельные эталонные JAR и пути, перечисленные в их `--help`.

В рабочей среде проверка использовала реальные зависимости из локального Maven и адаптацию NeoForm Runtime для ограниченного `/proc`. Этот кеш и изменённый инструмент в репозиторий не включены. Сборка на другом компьютере отдельно не проверялась; полная офлайн-сборка из одного репозитория не заявлена.

## Целостность и проверки

Для проверки сохранённой контрольной точки выполнить `python tools/verify_source_checkpoint.py` (нужен Python 3). `SOURCE-MANIFEST.json` содержит размеры и SHA-256 файлов снимка, кроме самого манифеста. Проверяющий скрипт ничего не меняет; после собственных правок отличия от снимка ожидаемы.

Для alpha.9.17-dev прошли **1990 JUnit-тестов, 56 серверных GameTests, генерация данных и сборка**. Настоящий клиент 1.21.1 проверен в 12 сценариях наведения + Shift и 6 сценариях таумометра. Оригинальный TC6 также запускался на Minecraft 1.12.2 для сравнения. Подробности и ограничения: [отчёт alpha.9.17](docs/THAUMOMETER-alpha9.17-CHECK.ru.md), [машиночитаемый итог](verification/development-thaumometer/summary.json) и материалы в `verification/development-thaumometer/`.

В GitHub сохранены код, игровые ресурсы, тесты и текстовые отчёты. Дополнительные изображения, видео, записи звука и двоичные файлы проверок из `verification/`, а также прежний DOCX для тестирования хранятся отдельно и не входят в репозиторий. Исторические отчёты могут ссылаться на эти внешние материалы.

Эти результаты относятся к сохранённой версии до переноса в GitHub, а не к новой проверке на каждом компьютере. Клиентские сценарии выполнены с программным OpenGL в отдельных одиночных мирах; новый тест двух клиентов на выделенном сервере в alpha.9.17 не проводился. Звук проверен по исходным файлам и фактическим событиям воспроизведения, без заявления о прослушивании.

## Сохранения и состояние переноса

Репозиторий хранит проект. Игровые сохранения, `playerdata`, данные и конфигурацию мира нужно резервировать отдельно при выключенной игре или сервере. Порт не конвертирует миры TC6 1.12.2.

Изменения таумометра и аспектов alpha.9.17 работают в существующих мирах. Изменения генерации деревьев, руд и кристаллов из alpha.9.15–alpha.9.16 действуют в новых чанках. Цвет существующей листвы обновляется без создания нового мира.

Полный перенос всех игровых систем ещё не завершён. Текущий объём работ описан в [DEVELOPMENT.md](DEVELOPMENT.md) и [PORTING-16.md](PORTING-16.md); наличие ресурсов или страниц исследований не подтверждает готовность соответствующей механики.

История предыдущих версий сохранена в [CHANGELOG.ru.md](CHANGELOG.ru.md), [README.ru.md](README.ru.md) и отчётах `docs/` и `verification/`. В частности, проверки книги alpha.9.14 находятся в `docs/THAUMONOMICON-alpha9.14-CHECK.ru.md`, деревьев alpha.9.15 — в `docs/WORLDGEN-alpha9.15-CHECK.ru.md`, руд alpha.9.16 — в `docs/ORES-alpha9.16-CHECK.ru.md`. Исторические протоколы, числа тестов и ограничения относятся к соответствующим выпускам.
