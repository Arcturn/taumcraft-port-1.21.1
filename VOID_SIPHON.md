# Пустотный сифон — alpha.9.41

Пункт 8 плана: действующий пустотный сифон `thaumcraft:void_siphon`, извлекающий семена пустоты из разломов. Механика, окно и эффекты перенесены из Thaumcraft 6 BETA26.

## Использование

1. Создайте сифон на рунической матрице после исследования `VOIDSIPHON`. Существующий рецепт соответствует оригиналу: блок пустотного металла, два магических камня, сложный механизм, две латунные пластины и звезда Нижнего мира; Alienis 50, Perditio 50, Vacuos 100, Fabrico 50; нестабильность 7.
2. Поставьте его рядом с разломом, оставив открытый путь между устройством и разломом. Область поиска — куб 16×16×16 блоков с центром в сифоне; учитываются пересекающие его разломы.
3. Забирайте семена через окно по ПКМ либо воронкой. Один выходной слот хранит до 64 семян. Ввод предметов через окно и автоматизацию запрещён.
4. Сигнал красного камня отключает добычу и звёздные поверхности устройства. Накопленный прогресс сохраняется.

## Добыча и влияние на разлом

Раз в 20 тиков сифон обрабатывает каждый видимый живой разлом размером не меньше 2. Разрушающиеся разломы тоже подходят, пока удовлетворяют этим условиям. Жидкости не перекрывают путь; блоки со столкновениями могут его перекрыть.

| За один цикл для каждого разлома | Значение |
| --- | --- |
| Прибавка прогресса | `floor(sqrt(размер))` |
| Потеря стабильности разлома | `sqrt(размер) / 15` |
| Вероятность уменьшения размера на 1 | `1 / 33` |
| Цена одного семени | 2000 прогресса |

Округление выполняется отдельно для каждого разлома. Например, разлом размера 100 даёт 10 прогресса за цикл, если его размер не меняется. Сифон не требует топлива или эссенции. При заполненном выходе он прекращает обработку разломов. Остаток прогресса после выпуска семени сохраняется.

Раз в 40 тиков активная добыча запускает исходный поток от видимых разломов к сифону. В окне используется исходная текстура и один выходной слот; отдельной полосы прогресса в BETA26 нет.

## Сохранение и адаптация

Сохраняются предметы и частичный прогресс. При разрушении блока содержимое выпадает, а незавершённый прогресс теряется, как в оригинале. Автоматизация может извлекать предметы с любой стороны.

Устранены ошибки старой реализации: прогресс записывается целым числом вместо короткого, каждое его изменение помечает блок для сохранения; готовые семена из накопленного остатка выдаются после освобождения полного слота без повторного расходования разлома. Shift-клик не позволяет складывать предметы обратно в выходной слот. Проверка видимости не загружает отсутствующие чанки.

При запуске схлопывания разлом запоминает текущий размер для расчёта добычи, поэтому предшествующая работа сифона влияет на результат. Повторный вызов схлопывания не перезаписывает уже зафиксированное значение. Причинный коллапсер остаётся пунктом 9 плана.
