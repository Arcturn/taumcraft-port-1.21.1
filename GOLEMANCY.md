# Големантия TC6 BETA26

Перенос для Minecraft 1.21.1 / NeoForge, начиная с alpha.9.36. Рецепты и требования исследований сохранены из оригинального раздела «Големантия».

## Сборка и управление

1. Откройте исследование механического разума. Соберите схему пресса из Таумономикона: поршень вверх, железные прутья над ним, котёл, наковальня и каменный стол. Примените Salis Mundus к одной из частей. Формирование занимает 50 тиков и расходует одну пыль.
2. Откройте пресс и выберите изученные материал, голову, руки, ноги и дополнение. Нужные компоненты берутся из инвентарей рядом с основной, поршневой частью пресса, кроме верхнего, либо из основного инвентаря игрока. Для одного ингредиента частичные количества из этих двух источников не складываются — так работает TC6.
3. Подайте Machina снизу или сбоку к основной части пресса. Детали списываются один раз при запуске; пресс расходует одну единицу эссенции каждые 5 тиков. Незавершённая сборка сохраняется, а несовместимый или заполненный выход задерживает выдачу готового голема.
4. Поставьте готового голема на блок. Он запоминает владельца и домашнюю точку. Обычная дальность работы от дома — 32 блока; свойство разведчика увеличивает её до 48.
5. Разместите печати, настройте их колокольчиком и обеспечьте доступ к заданиям. Голему нужны подходящие свойства, свободное место для груза и проходимый маршрут.

После исследования прямого управления ПКМ колокольчиком по своему голему переключает следование и работу у новой домашней точки. Shift+ПКМ по своему голему упаковывает его с сохранением конструкции, ранга и опыта; груз предварительно выгружается. Краситель задаёт цвет группы.

ПКМ колокольчиком по печати открывает её настройки; Shift+ПКМ снимает печать. Нулевой цвет не ограничивает совместимость; два ненулевых цвета должны совпадать. Замок разрешает работу только големам владельца печати. Как в BETA26, замок не запрещает другим игрокам открывать или снимать саму печать; менять замок и настройку красного камня может только её владелец.

## Конструкция

| Часть | Варианты |
|---|---|
| Материал | Великая древесина, железо, обожжённая глина (терракота), латунь, таумий, пустотный металл |
| Голова | Обычная, биотаумическая, защищённая биотаумическая, разведчик, биотаумический разведчик |
| Руки | Обычные, точные, когти, разрушители, стрелковые |
| Ноги | Ходящие, колесо, лазающие, летающие |
| Дополнение | Без дополнения, броня, боец, носильщик |

Всего 2400 сочетаний. Детали задают 19 исходных свойств; противоположные свойства взаимно отменяются. Материал влияет на здоровье, броню, урон и устойчивость. Носильщик переносит две стопки вместо одной. Разумные големы получают опыт за работу и бой и могут достигать ранга 10; порог следующего ранга — `(ранг + 1)² × 1000` опыта.

## Печати

| Печать | Работа |
|---|---|
| Подбор / улучшенный подбор | Подбор подходящих лежащих предметов в области |
| Наполнение / улучшенное наполнение | Доставка груза в инвентарь либо на землю с учётом фильтра и количества |
| Опустошение / улучшенное опустошение | Изъятие из инвентаря; улучшенные настройки включают циклический выбор и сохранение одного предмета |
| Снабжение | Выдача предметов для запросов логистики и пополнения через физическую доставку големом |
| Пополнение | Поддержание заданного количества в инвентаре через запросы снабжения |
| Жатва | Сбор созревших культур и повторная посадка семенами |
| Забой | Выбор лишних взрослых животных с сохранением пары; детёныши и приручённые животные исключаются |
| Охрана / улучшенная охрана | Выбор целей для боя в области с исходными категориями целей |
| Лесоруб | Последовательная рубка подходящих стволов |
| Разрушение / улучшенное разрушение | Разрушение блоков с учётом твёрдости, доступа и настроек фильтра/шёлкового касания |
| Использование | Правое или левое действие переносимым предметом либо пустой рукой; можно запросить предмет из белого списка у снабжения |

Фильтры содержат образцы: помещение предмета в фильтр не передаёт его печати. В белом списке наполнения `0` означает отсутствие ограничения; у пополнения это целевой запас, поэтому для заказа нужно указать положительное количество. Приоритет влияет на выбор задания вместе с расстоянием. Печати не загружают чанки принудительно, в том числе при проверке красного камня: питание учитывается только от уже загруженных соседей, включая передачу через проводящий блок.

После открытия логистики Shift+ПКМ колокольчиком в воздух открывает заказ с доставкой игроку, а по подходящей стороне инвентаря — доставку в него. Каталог показывает содержимое собственных печатей снабжения в пределах 32 блоков. Предметы приносит голем; одного наличия предмета в каталоге недостаточно для мгновенной выдачи.

## Адаптация и сохранение

Сохраняются части, владелец, домашняя точка, цвет, ранг, опыт и груз голема; настройки печатей, фильтры и работа пресса. Очередь заданий временная: после загрузки печати заново создают обычные задания, как в оригинале. Разовые заказы из меню логистики не сохраняются; после перезагрузки их нужно повторить. Срок заданий уменьшается раз в 20 тиков.

Ore Dictionary заменён общими тегами Minecraft/NeoForge; старые метаданные предметов — современными компонентами и отдельными предметами. Взаимодействия с блоками проходят современные проверки от имени владельца, включая отмену действий защитными модами.

Исправлены ошибки оригинала, приводившие к потере или подмене предметов: пустая рука печати использования не уничтожает груз, фильтр с игнорированием компонентов извлекает настоящий предмет с его компонентами, отменённый выброс сохраняет остаток для повторного возврата. Исправлен учёт предметов на земле при наполнении с лимитом и очистка очереди повторной посадки. Идентификаторы заданий не зависят от совпадений времени создания.

Некоторые необычные правила оригинала сохранены: заполненные пункты белого списка улучшенного разрушения проверяются совместно; левое действие печати использования является одним ударом/началом разрушения, поэтому для последовательной добычи твёрдых блоков нужна печать разрушения.

Големы этого раздела — создаваемые игроком помощники. Потусторонний голем-босс и незавершённые системы других разделов не входят в этот перенос.
