# Alpha.8: банки, распорки, бирки и мехи

Для Minecraft 1.21.1 / NeoForge / Curios. Оставьте в `mods` только один JAR порта — alpha.8. Проверяйте в отдельном тестовом мире с командами. Старые сценарии остаются в `CHECKLIST.ru.md`, `ESSENTIA-CHECK.ru.md` и `ESSENTIA-EXTENSIONS-CHECK.ru.md`.

Это ручной чек-лист, а не отчёт о выполненных игровых тестах. Дистанционные устройства и наполнение ещё не реализованы: распорка уже закрывает программный интерфейс источника, но проверить готовый ритуал с ней пока нельзя.

## 1. Подготовка стенда

Перейдите в свободное место. Абсолютные координаты ниже — пример, занятые блоки будут заменены.

```mcfunction
/gamemode creative
/give @s thaumcraft:jar_normal 8
/give @s thaumcraft:jar_void 4
/give @s thaumcraft:jar_brace 8
/give @s thaumcraft:label 8
/give @s thaumcraft:phial 16
/give @s thaumcraft:tube 16
/give @s thaumcraft:bellows 6
/give @s thaumcraft:tube_buffer
/give @s thaumcraft:thaumometer
/setblock 0 100 0 thaumcraft:jar_normal{Aspect:"ignis",Amount:80,Filter:"ignis",LabelFacing:5}
/setblock 2 100 0 thaumcraft:alembic{Aspect:"ignis",Amount:128}
/tp @s 0 101 4
```

## 2. Распорка и сохранение

- [ ] Навести курсор на распорку в инвентаре: есть текстура и подсказка.
- [ ] ПКМ распоркой по банке в Survival: расходуется одна, виден латунный ободок, звучит `key`.
- [ ] Повторный ПКМ не расходует вторую. На перегонный куб распорка не устанавливается.
- [ ] Пустая колба берёт из укреплённой банки 10 Ignis; заполненная возвращает 10. Верхняя труба продолжает работать.
- [ ] Проверить состояние:

```mcfunction
/data get block 0 100 0
```

Ожидается `Braced: 1b`. Для проверки настоящего дропа перейдите в Survival и разбейте банку: одна банка с остатком эссенции и одна отдельная распорка. Установленная заново банка сохраняет эссенцию/фильтр, но не ободок. Повторное разбивание не выдаёт ещё одну распорку. В Creative обычное разрушение блока не проверяет Survival loot.

- [ ] С укреплённой банкой на месте сохраните мир, выйдите, зайдите: ободок/содержимое/сторона бирки сохраняются.
- [ ] Скрафтить распорку: латунные самородки по углам, деревянные палки посередине четырёх сторон, центр пустой. Результат — две распорки.

## 3. Заполнение банкой из куба

- [ ] ПКМ пустой банкой в руке по заполненному кубу: получается ровно одна банка с 128 Ignis; куб пустеет. Если в руке был стак, остальные банки остаются пустыми.
- [ ] Навести курсор на результат: подсказка показывает Ignis и количество.
- [ ] Установить банку, дополнить до 240 через команду ниже, разбить в Survival и взять предметом:

```mcfunction
/data merge block 0 100 0 {Aspect:"ignis",Amount:240,Filter:"ignis"}
/data merge block 2 100 0 {Aspect:"ignis",Amount:128}
```

ПКМ такой банкой по кубу переносит только 10: банка 250, куб 118. Полная банка больше не извлекает. Бирка другого аспекта запрещает заполнение. Пустотная банка в руке тоже берёт только свободный объём — содержимое куба не уничтожается сверх 250.

## 4. Бирки и соединения

- [ ] Наклеить бирки на банки, стоя с четырёх сторон. Бирка смотрит к игроку, иконка аспекта видна без чёрно-фиолетовой текстуры.
- [ ] Shift+ПКМ пустой рукой по стороне с биркой снимает только бирку и возвращает пустую бирку предметом; эссенция остаётся.
- [ ] Shift+ПКМ по другой стороне опустошает банку и загрязняет ауру; фильтр остаётся.
- [ ] Бирка куба ставится на выбранную боковую грань; верх/низ её не принимают. Помеченная грань перестаёт быть выходом трубы, остальные допустимые грани работают. После снятия бирки выход восстанавливается.
- [ ] При трубе над обычной/пустотной банкой виден короткий воротник. После удаления трубы он исчезает. Распорка и воротник могут отображаться одновременно.

## 5. Мехи и обычная печь

```mcfunction
/setblock 5 100 0 minecraft:furnace[facing=south]
/setblock 4 100 0 thaumcraft:bellows[facing=east,enabled=true]
/setblock 8 100 0 minecraft:furnace[facing=south]
/item replace block 5 100 0 container.0 with minecraft:iron_ore 32
/item replace block 8 100 0 container.0 with minecraft:iron_ore 32
/item replace block 5 100 0 container.1 with minecraft:coal 8
/item replace block 8 100 0 container.1 with minecraft:coal 8
```

- [ ] Первая печь работает быстрее контрольной. Одни мехи дают дополнительный тик готовки раз в два тика, когда рецепт уже начат и есть горение.
- [ ] Выпадает ровно один слиток на руду, опыт выдаёт сама печь; мехи не создают отдельного результата.
- [ ] Повернуть мехи от печи: ускорения нет. Подать редстоун: ускорение и движение мехов останавливаются. Убрать сигнал: возобновляются.
- [ ] Пустая/погасшая печь не начинает плавку от мехов. Коптильня и плавильная печь не ускоряются этим механизмом.
- [ ] Сжатие быстрое, расправление медленное; звук тихого выдоха появляется при полном расправлении. Несколько мехов начинают анимацию с небольшим рассогласованием.
- [ ] Направить мехи к буферу эссенции с каждой из шести сторон: соединительное сопло видно, оно не висит с противоположной стороны и не исчезает при обычном обзоре.

## Что прислать при сбое

Версию NeoForge/Curios, `logs/latest.log`, координаты и команду `/data get block X Y Z` для проблемного блока. Для графики — вид с проблемной стороны и направление мехов/бирки. Проверка двух игроков и выгрузки чанков пока остаётся отдельным этапом.
